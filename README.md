# ★ 스타벅스 타이쿤

작은 동네 스타벅스 매장을 운영해 글로벌 플래그십 스토어로 키우는 타이쿤 게임입니다. Next.js(App Router) + React로 만들었어요.

> 비상업적 팬메이드 게임입니다. 스타벅스와 무관하며, 공식 로고 이미지는 사용하지 않았습니다.

## 실행하기
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # 프로덕션 빌드
```
Vercel에 저장소를 연결하면 별도 설정 없이 배포됩니다.

## 플레이 방법
- 손님을 눌러 주문을 고르면 **주문서**에 필요한 재료가 표시됩니다.
- 재료 버튼으로 컵을 채우고 **서빙하기**. 빨리 낼수록 팁과 평판이 올라갑니다.
- 인내심 막대가 다 닳으면 손님이 떠나고 평판이 떨어집니다.
- 하루(약 100초) 영업이 끝나면 임대료·파트너 일당을 내고, 상점에서 업그레이드합니다.
- 잔고가 0 아래로 떨어지면 파산!

### 키보드
| 키 | 동작 |
|---|---|
| 1–9 | 재료 담기 |
| Q / W / E | 베이커리 담기 |
| ← / → | 손님 선택 |
| Space / Enter | 서빙 |
| X / Backspace | 버리기 |
| R | 레시피 북 |
| P / Esc | 일시정지 |

## 콘텐츠
- **음료 9종**: 카페 아메리카노, 아이스 카페 아메리카노, 카페 라떼 → 바닐라 라떼, 카라멜 마키아또, 돌체 라떼, 카페 모카, 제주 말차 라떼, 자바 칩 프라푸치노
- **베이커리 3종**: 버터 크루아상, 뉴욕 치즈 케이크, 햄 & 치즈 샌드위치
- **설비**: 리저브 원두(가격↑), 푹신한 소파(인내심↑), 사이렌 오더 홍보(손님↑), 매장 확장(대기 줄↑), 파트너 고용(자동 서빙)
- **일일 이벤트**: 출근 러시, 비 오는 날, 폭염, 시즌 프로모션
- **매장 등급**: 동네 매장 → 인기 매장 → DT 매장 → 리저브 매장 → 글로벌 플래그십
- 매일 아침 자동 저장 (브라우저 localStorage)

## 구조
```
app/layout.js        메타데이터, 폰트
app/page.js          <Game /> 렌더
app/globals.css      스타일
components/Game.jsx  화면 (HUD, 매장, 바 스테이션, 모달)
lib/engine.js        게임 규칙과 상태 (손님 생성, 서빙 판정, 하루 정산, 상점)
lib/data.js          메뉴·재료·업그레이드·이벤트 데이터 (밸런스 조정은 여기서)
lib/sound.js         WebAudio 효과음
```

# ★ 별다방 타이쿤

작은 동네 카페를 운영해 커피 제국으로 키우는 브라우저 타이쿤 게임입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 플레이 방법
- 손님을 눌러 주문을 고르면 **주문서**에 필요한 재료가 표시됩니다.
- 재료 버튼으로 컵을 채우고 **서빙하기**. 빨리 낼수록 팁과 평판이 올라갑니다.
- 인내심 막대가 다 닳으면 손님이 떠나고 평판이 떨어집니다.
- 하루(약 100초) 영업이 끝나면 임대료·인건비를 내고, 상점에서 업그레이드합니다.
- 잔고가 0 아래로 떨어지면 파산!

### 키보드
| 키 | 동작 |
|---|---|
| 1–9 | 재료 담기 |
| Q / W / E | 베이커리 담기 |
| ← / → | 손님 선택 |
| Space / Enter | 서빙 |
| X / Backspace | 버리기 |
| R | 레시피 북 |
| P / Esc | 일시정지 |

## 콘텐츠
- **메뉴 8종**: 아메리카노, 아이스 아메리카노, 카페 라떼 → 바닐라 라떼, 카라멜 마키아또, 카페 모카, 녹차 라떼, 자바칩 프라페 (상점에서 개발)
- **베이커리 3종**: 크루아상, 치즈케이크, 샌드위치
- **설비 업그레이드**: 고급 원두(가격↑), 푹신한 소파(인내심↑), SNS 마케팅(손님↑), 매장 확장(대기 줄↑), 바리스타 고용(자동 서빙)
- **일일 이벤트**: 출근 러시, 비 오는 날, 폭염, 인플루언서 방문
- **매장 등급**: 동네 카페 → 인기 카페 → 지역 명소 → 체인 본점 → 커피 제국
- 매일 아침 자동 저장 (브라우저 localStorage)

※ 팬메이드 게임으로, 실제 브랜드의 로고나 상표 이미지는 사용하지 않았습니다.
